Privacy Policy

Effective: November 9, 2026

Who we are

Shorts Factory is a personal tool operated by a single individual (contact: alaikkum@gmail.com) to manage that individual's own YouTube channels.

Data we access

  • With the YouTube Data API (scopes youtube.upload and youtube.force-ssl): uploading videos, setting video metadata and thumbnails, and reading video statistics and public comments on the operator's own channels.
  • With the YouTube Analytics API (scope yt-analytics.readonly): reading aggregate performance metrics (views, watch time, retention, subscribers gained) for the operator's own videos.
  • Public data from the YouTube Data API (video titles, view counts, public comments) to research publicly trending videos.

How data is used and stored

Data is used only to publish videos and to measure how they perform so future videos can be improved. OAuth tokens and statistics are stored locally on the operator's own computer. No data is sold, shared with third parties, or used for advertising. Comment text may be summarized by an AI model to understand audience reactions.

Google API Services User Data Policy

Shorts Factory's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. YouTube API Services are used in accordance with the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at Google Account permissions. Locally stored data is deleted when access is revoked or on request.
