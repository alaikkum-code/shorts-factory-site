Shorts Factory

Shorts Factory is a private, single-operator tool that produces short educational videos and publishes them to YouTube channels owned by its operator.

It uses the YouTube Data API and YouTube Analytics API only to upload videos, set titles, descriptions and thumbnails, and read performance statistics and comments for the operator's own channels. It is not offered to the public and does not access anyone else's account.

YouTube API Services

Shorts Factory uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See the Google Privacy Policy and our Privacy Policy for how data is handled. Access can be revoked at Google Account permissions.
